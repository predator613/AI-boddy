# API: цели стажировки и справочник

Все запросы с заголовком `Authorization: Bearer <token>`. Ошибки: `{ "error": { "code", "message" } }`. Чужие данные отвечают 404 (не раскрываем, что они есть), запрещенные для роли действия – 403. Данные демо-синтетические и не являются регламентами Авито.

## Цели стажировки

На 1-й неделе стажер обсуждает с руководителем цели, критерии успеха и OKR команды, на 2-й вносит их в трекер прогресса, дальше отмечает продвижение. Наставник видит обновления и получает уведомление.

| Метод | Путь | Кто | Ответ |
|---|---|---|---|
| GET | /api/goals | стажер | GoalsView (свои цели) |
| GET | /api/interns/{internId}/goals | наставник стажера, руководитель команды | GoalsView |
| POST | /api/goals/{goalId}/progress | стажер, его наставник, руководитель | Goal |
| POST | /api/interns/{internId}/goals | наставник, руководитель; стажер – пока цели не согласованы | Goal (201) |
| PATCH | /api/goals/{goalId} | так же | Goal |
| DELETE | /api/goals/{goalId} | так же | 204 |
| POST | /api/interns/{internId}/goals/agree | только руководитель команды | GoalsView |

### GoalsView

```json
{
  "internId": "aaaaaaaa-0000-4000-8000-000000000001",
  "agreed": { "by": { "id": "aaaa…0003", "name": "Артемий" }, "at": "2026-11-04T10:00:00+03:00" },
  "fromOkr": true,
  "goals": [{
    "id": "f300…0002", "position": 2,
    "title": "Разобраться в сервисе авторизации",
    "criterion": "провести демо команде на 8 неделе",
    "dueWeek": 8, "progressPct": 10,
    "okr": { "id": "f200…0001", "period": "Q4 2026", "title": "Ускорить выпуск изменений в сервисе авторизации" },
    "lastUpdate": { "author": { "id": "aaaa…0001", "name": "Мария" }, "progressPct": 10, "note": "Прочитала документацию сервиса", "at": "…" },
    "updatedAt": "…",
    "createdBy": { "id": "aaaa…0003", "name": "Артемий" }
  }],
  "okrs": [{ "id": "f200…0001", "period": "Q4 2026", "title": "…" }],
  "canEdit": false,
  "canAgree": false
}
```

- `agreed: null` – цели еще не согласованы (бейдж «еще не согласованы»).
- `fromOkr` – хотя бы одна цель привязана к OKR команды (в бейдже «· от OKR команды»).
- `canEdit` – можно ли этому пользователю добавлять и менять цели; `canAgree` – показать кнопку «Согласовать цели».

### Тела запросов

- POST progress: `{ "progressPct": 0..100, "note": "до 500 символов, необязательно" }`.
- POST goals: `{ "title": "до 120", "criterion": "до 160", "dueWeek": 1..52, "okrId": "id OKR своей команды" }` – `dueWeek` и `okrId` необязательны. Не больше 6 целей.
- PATCH: те же поля, все необязательны; отсутствующее поле не меняется, `dueWeek: 0` и `okrId: ""` очищают значение.

## Справочник

| Метод | Путь | Ответ |
|---|---|---|
| GET | /api/kb | `{ sections, articles, terms }` – формат схемы `KnowledgeBase` фронта |
| GET | /api/kb/articles/{articleId} | статья с текстом |
| GET | /api/kb/search?q=...&limit=10 | `{ query, results }`, до 20 результатов |

Пользователь видит общие материалы и материалы своей команды. `sections[].id` – код раздела (`s-access`), `count` считает только видимые статьи. `articles[].stageCode` – номер этапа пути команды пользователя («02») или `null`. `minutes` – время чтения (180 слов в минуту, минимум 1).

### Статья

```json
{
  "id": "c200…0004", "sectionId": "s-access", "title": "Как запросить доступ к сервису",
  "summary": "…", "minutes": 1, "stageCode": "02",
  "body": "Абзац 1.\n\nАбзац 2.", "source": "seed", "url": null,
  "authorName": null, "useInAi": true, "updatedAt": "…"
}
```

`source`: `seed`, `upload`, `link`, `mentor_answer` (ответ наставника, сохраненный из переписки).

### Поиск

PostgreSQL full-text с русской морфологией: «отгул» находит «отгулы», запрос понимается как «любое из слов», совпадение в заголовке весит вдвое больше, чем в тексте. Из каждой статьи берется лучший фрагмент.

```json
{ "query": "отгул", "results": [{ "articleId": "c200…0012", "sectionId": "s-leave", "title": "Как взять отгул",
  "summary": "…", "snippet": "Отгул оформляется заявкой…", "stageCode": null, "score": 0.42 }] }
```

Пустой `q` или длиннее 200 символов – 400. Ничего не найдено – пустой `results`.
