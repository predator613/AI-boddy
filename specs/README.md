# Спецификации (SDD)

Формат spec-kit: на каждую функцию папка `NNN-название` с тремя файлами.

- `spec.md` – что и зачем: пользовательские истории, требования, критерии приемки. Без технологий.
- `plan.md` – как: архитектура, данные, API, решения и их причины.
- `tasks.md` – шаги реализации с отметками и ссылками на тесты.
